# Week 11 — Data Visualization / Data Portraiture

## Project
**A City of Requests** uses NYC's public 311 service-request dataset to compare the most frequently reported complaint categories across the five boroughs.

## Research question
Which kinds of 311 service requests appear most often in each NYC borough, and how does that pattern change by place?

## Data source and method
The sketch uses the [NYC Open Data 311 Service Requests dataset](https://data.cityofnewyork.us/resource/erm2-nwe9.json). It filters records created during 2025, groups them by borough and complaint type, and displays the leading request categories for a selected borough. The viewer can compare all boroughs.

## Why this data?
311 is a public interface through which residents report issues to city agencies. The data offers a way to explore what kinds of needs become visible through this reporting system. It is useful because it is both geographically organized and categorized by request type.

## What the visualization reveals—and hides
The chart makes it easier to compare the categories that appear most often in the returned records. However, a 311 request is not proof that a problem was verified, and the dataset is not a complete record of every issue in a neighborhood. It reflects what people report, what they know how to report, and how the city categorizes those reports. These limitations are part of the project's argument, not a footnote.

## Interaction

- Press A to compare all boroughs.
- Press R to refresh the data.
