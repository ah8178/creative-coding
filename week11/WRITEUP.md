# Week 11 — Data Visualization / Data Portraiture

## Project description
For this project, I created a data visualization using NYC subway hourly ridership data from NY Open Data. The sketch requests a sample of the most recent 2,000 records from the public dataset and groups the ridership values by hour of day. Each bar represents the summed ridership values for that hour within the returned sample. The visualization uses the height of each bar to make differences between hours easier to compare.

My question is: **How is subway ridership distributed across the hours represented in a recent sample of NYC MTA data?**

Data source: [MTA Subway Hourly Ridership (2020–present), NY Open Data](https://data.ny.gov/Transportation/MTA-Subway-Hourly-Ridership-2020-Present/wujg-7c2s).

## Reflection
Data visualization is interesting to me because it allows information to be communicated through visual elements rather than just numbers and text. I realized that the way data is presented can influence how people understand a subject. A dataset might seem ordinary on its own, but when it is organized visually, patterns and relationships become easier to recognize. I am particularly interested in how movement and time can be represented through visual forms. This project also made me think about the information that gets left out when data is collected. A visualization can communicate certain patterns while hiding others depending on how it is designed. I want to experiment with making data feel more interactive and personal instead of treating it as a collection of statistics.

## Data limitation
This sketch uses a limited sample of the newest records returned by the API, not a complete day or a representative sample of every station. The chart should therefore be interpreted as an exploration of the returned sample, not as a definitive picture of all NYC subway travel.
