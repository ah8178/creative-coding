## 2. Concept
Clock in Space explores how time can be experienced as a spatial and visual event rather than only read as numbers on a screen. I want to develop a clock animation that responds to the geometry of a physical surface. Instead of placing a standard clock face onto a wall or object, the movement of time will become a sequence of lines, pulses, and shifting forms that wrap around the mapped surfaces.

## 3. How the new work will respond to the earlier work
The earlier clock sketch provides the underlying time-based logic, while the projection-mapping exercise provides the physical context. The new version will be more deliberate in its visual system and will use the shape of the projection surface as part of the composition. I want to improve the relationship between the animation and the physical environment, rather than treating projection as simply a larger display.

The main challenge will be making the animation legible on an irregular or multi-part surface. I will need to test how projection changes color, contrast, and scale, and how the animation can remain coherent when it crosses between surfaces.
