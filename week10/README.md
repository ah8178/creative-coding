# Week 10 — Gestural Control

**Course brief:** Use an ml5.js model (FaceMesh, HandPose, or BodyPose) with webcam input to control parameters in a p5.js sketch.

## Project: Gesture Garden

- Move the index finger to steer the visual field.
- Finger height changes the hue.
- Pinching the thumb and index finger creates blooms; pinch distance changes their size.
- The sketch uses ml5 HandPose and the webcam.

## Run it

Open `index.html` with VS Code Live Server. Camera access requires localhost or HTTPS. Allow webcam permission when the browser asks.
